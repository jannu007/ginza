# GINZA AI OFFICE

銀座発、AI会社運営支援オフィスのホームページです。
経理・秘書・採用・法務・議事録・競合分析・接客という、会社運営に欠かせない7つの業務を
**その場で実際に動くAIツール**として無料で提供します。

フレームワークやビルドツールを使わない、素の HTML / CSS / JavaScript のみで構成しているため、
静的ホスティングにそのまま置くだけで公開できます。

## 構成

```
.
├── index.html                # ページ本体（ホームページ + 7つのツールのモーダル）
├── assets/
│   ├── css/style.css         # 銀座の夜をイメージした金×黒×朱のデザイン
│   └── js/
│       ├── main.js           # ローダー・カーソル・スクロール演出・粒子背景・モーダル制御
│       └── tools.js          # 7つのAIツールのロジック本体
└── README.md
```

## 7つのAIツール

| # | ツール名 | 内容 |
|---|---|---|
| 壱 | AI秘書 | タスクの重要度・締切から、1日のスケジュールを自動で並べ替え |
| 弐 | AI経理アシスタント | 経費品目からカテゴリ別集計・消費税を自動計算 |
| 参 | AI採用サポーター | 職種・必須スキルを入れるだけで求人票を自動生成 |
| 肆 | AI議事録メーカー | 箇条書きメモを決定事項・ネクストアクション付き議事録に整形 |
| 伍 | AI契約書チェッカー | 契約書本文からリスク条項キーワードを自動検出 |
| 陸 | AI競合分析アシスタント | 強み・弱み・機会・脅威をSWOTマトリクスに整理 |
| 漆 | AIカスタマーサポート | よくある質問に答える受付AIチャット |

いずれもサーバーやAPIキーを使わず、ブラウザ内のロジックだけで完結する
実際に操作できるミニアプリとして実装しています。

## ローカルで確認する

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 無料で公開する方法（おすすめ: GitHub Pages）

1. このリポジトリを GitHub にプッシュする
2. `Settings` → `Pages` を開く
3. `Source` を `Deploy from a branch` にし、対象ブランチと `/ (root)` を選択して `Save`
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## カスタマイズのポイント

- **会社名・キャッチコピー**: `index.html` の `<h1 class="hero-title">` 付近
- **AIツールの内容**: `index.html` の `.tool-card` と対応する `.modal-overlay`、ロジックは `assets/js/tools.js`
- **配色**: `assets/css/style.css` 冒頭の `:root` 変数（`--gold` / `--seal` など）
- **連絡先**: `index.html` 内の `mailto:hello@ginza-ai-office.jp` を実際のメールアドレスに変更
